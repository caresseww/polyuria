🧭 核心心法：多尿不是病，是肾脏在报数

多尿 = 尿量 >4–5 mL/(kg·h) 或 >150 mL/(kg·d) 持续 >24 h。它永远是结果——背后只有一个问题：尿为什么留不住？本指南把全部鉴别压缩成一张三要素地图：任何一个多尿的患儿，都能定位到三个环节中的一环或多环失效。

核心公理：浓缩三要素模型
肾脏把原尿浓缩成终尿，靠三个相互独立、缺一不可的环节：① 髓质高渗梯度（水的"势能"）、② AVP–V2–AQP2 轴（放水的"阀门"）、③ 溶质排泄负荷（必须带走的"货"）。梯度坏、阀门坏 = 水利尿（尿渗 <200，低渗尿）；货多 = 溶质性利尿（尿渗 >300，等/高渗尿）。→ 第②页 把三要素讲透

基础

尿液是怎么被浓缩的：三要素模型

肾小球每天滤出约 180 L 原尿，渗透浓度与血浆相同；终尿只有 1–2 L——99% 的水被重吸收。理解下面三个环节，就理解了全部多尿的鉴别诊断。

要素一 · 髓质高渗梯度
逆流倍增造出"水的势能"：髓袢升支粗段主动重吸收 NaCl（Na⁺-K⁺-2Cl⁻ 同向转运体 NKCC2）但对水不通透 → 把溶质泵进髓质间质；尿素从内髓集合管再循环，贡献约一半髓质高渗；直小血管逆流交换带走多余溶质但保留梯度。梯度：皮质 300 → 外髓 600 → 内髓 900 → 乳头 1200 mOsm/kg。
破坏因素：髓袢坏死/纤维化、呋塞米（抑制 NKCC2）、低蛋白/低尿素饮食、直小血管血流过快。
要素二 · AVP–V2–AQP2 轴
放水的"阀门"。AVP（九肽）由下丘脑视上核/室旁核合成，经下丘脑-垂体束运到神经垂体储存释放；结合集合管主细胞 V2 受体 → cAMP → PKA → AQP2 水通道插入顶膜；水顺梯度经 AQP2 入细胞、AQP3/AQP4 出细胞回血流。
此环节坏 = 尿崩症（DI）：AVP 没分泌是 CDI（中枢性）；V2/AQP2 坏了是 NDI（肾性）。
要素三 · 溶质排泄负荷
必须带走的"货"。每日必须排出代谢溶质（尿素约 450 mOsm/d + 电解质）；尿量 = 溶质排泄量 ÷ 尿浓度——即使浓缩功能正常，溶质多就必须多排尿。
此环节多 = 溶质性利尿：高血糖、高氨基酸、大量钠。
🔑 一句话定位所有病因
水利尿（尿渗 <200）= 梯度坏或阀门坏：医源性多水、DI 家族、肾小管病。溶质性利尿（尿渗 >300）= 货多：高血糖、TPN、梗阻后、ATN 多尿期。遇到多尿，先问"这三个环节哪个坏了"，再问"为什么坏"。

深水区

新生儿肾血流动力学：为什么早产儿尿更稀

  • RBF 与 GFR 未成熟：足月新生儿 GFR 仅成人 30%（按体表面积校正），早产儿更低；生后 2 年才达成人。
  • 髓质血流相对高：直小血管逆流交换效率低，容易"冲走"髓质高渗——新生儿最大尿渗低的物理原因之一。
  • 前列腺素相对优势：新生儿肾脏 PGE2 合成活跃（维持 RBF），等于持续踩 AQP2 的"刹车"——新生儿尿本来就稀的分子解释。
  • 钠重吸收不成熟：近端小管重吸收相对多 → 到达髓袢的溶质减少，逆流倍增效率低；远端肾单位调节精细度差。
临床推论：早产儿用吲哚美辛关闭 PDA 时双重影响——一方面抑制 PGE2 去掉刹车让尿变浓，另一方面收缩肾血管降低 RBF → 必须监测尿量和肌酐。
深水区

为什么呋塞米是"可逆性 NDI"、噻嗪反而治 NDI

呋塞米抑制髓袢升支粗段 NKCC2 → 髓质高渗梯度被打散 → 即使 AVP 正常、AQP2 正常，集合管周围没有高渗梯度可依，水也回不来。这就是 NICU 里呋塞米后多尿为什么是低渗尿——它制造了一个"可逆的肾性尿崩"。
反过来，NDI 用氢氯噻嗪的逻辑：噻嗪抑制远曲小管 NaCl 重吸收 → 轻度容量耗竭 → 近端小管钠和水重吸收代偿性增加 → 到达髓袢/集合管的原尿减少 → 尿量减少。"以毒攻毒"——治疗剂量页有完整方案（第⑩页）。

主线

床旁五步分流法（值班主线）

1
复核出入量 + 医嘱用药清单（零成本，5 分钟，永远排第一）
补液总量与糖速、TPN 成分；呋塞米、氨茶碱/咖啡因、糖皮质激素、甘露醇、两性霉素 B、吲哚美辛/布洛芬、光疗补液。有医源性因素 → 先做停药/减量试验。→ 第⑥页 医源性清单
2
一条指尖血糖 + 尿糖
1 分钟排除新生儿糖尿病与应激性高血糖溶质性利尿。高血糖时血钠被稀释，记得校正（血糖每高 5.6 mmol/L，实测 Na +1.6）。→ 第⑧页 高血糖
3
同步血钠 + 精测尿比重 / 尿渗透压
这是分水岭：尿渗 <200 = 水利尿（DI 家族、医源性），>300 = 溶质性，200–300 = 灰区（部分性 DI、梗阻后、ATN 多尿期）。床旁速算：比重末两位 ×40 ≈ 尿渗。
4
按类定向检查
水利尿 → DI 轴：DDAVP 试验、垂体 MRI；NDI 轴：血钙血钾、泌尿系超声、AVPR2→AQP2 基因。溶质性 → 按溶质来源（糖/氨基酸/电解质/梗阻）。→ 第⑥页 → 第⑦页 → 第⑧页
5
容量评估贯穿始终（安全阀）
皮肤弹性、前囟、黏膜、毛细血管再充盈、心率血压、体重趋势。低容脱水决定补液速度与降钠安全；等/高容则警惕 SIADH。→ 第④页 高钠 → 第⑤页 低钠
本页其余各节都挂在这五步上：起病时间窗与病史/查体清单支撑第 ①② 步，分层化验支撑第 ④ 步，页底「尿渗一刀」是第 ③ 步的展开。

核心分流

尿渗透压一刀分两类

看到多尿，先测尿渗透压 + 同步血生化，再按血钠、血糖、用药二次分流。这一刀切下去，病因范围立刻缩小 80%。

尿渗 <200 · 水利尿（低渗尿）
排的是"纯水"——梯度或阀门坏了。再看血钠分流：
  • 血钠 >145 → DI 家族：先排医源性（呋塞米/补液），再做 DDAVP 试验分 CDI vs NDI
  • 血钠低/正常 → 补液过量、多饮；尿钠>40＋脑损伤史 → SIADH / CSW（第⑤页）
  • 血钙↑/血钾↓ → 获得性 NDI，先纠正
尿渗 200–300 · 灰区
不典型，动态复测 + 定向：
  • 部分性 DI（CDI/NDI 轻型，残余浓缩功能）
  • 梗阻后利尿（男婴 PUV 术后，尿钠高）
  • ATN 多尿期（窒息/肾静脉血栓后少尿转多尿）
  • 利尿剂消退期、稀释功能恢复期
尿渗 >300 · 溶质性利尿（等/高渗尿）
尿里"带着货"——先找货从哪来：
  • 血糖高 → 应激性高血糖 / 新生儿糖尿病
  • 尿钠高 + 梗阻史 → PUV 梗阻后利尿

急症

高钠血症：先保脑，再查因

血钠 >145 mmol/L。多尿 + 高钠的患儿，首先要回答的不是"什么原因"，而是"脑现在安全吗"。降钠速度错了，病因查得再清楚也会留下残疾。

⚡ 一条铁律：速度天花板是被脑细胞"锁死"的
降钠 ≤0.5 mmol/(L·h)、≤10–12 mmol/(L·24 h)、总纠正 48–72 h 匀速降到 145–150——这不是经验，是被脑细胞拆除"渗透分子"的速度锁死的。新生儿起病时间几乎总无法确定，一律按慢性高钠处理。

双向病理：为什么"快"和"慢"都出事

急性高钠（<24–48 h）· 出血风险
细胞外高渗，水被拉出脑 → 脑实质皱缩 → 桥静脉被拉断 → 颅内出血、脑静脉窦血栓。纠正反而可以稍快（≤1 mmol/(L·h)）——有机渗透物尚未生成。
慢性高钠（>48–72 h）· 水肿风险
脑细胞合成肌醇、甜菜碱、牛磺酸等"idiogenic osmoles"把细胞内渗透压顶上去——这层自我保护需 ~48–72 h 建立，是治疗的时间锁。此时快速降钠 → 细胞外突然变低渗，渗透分子来不及拆 → 水冲进脑细胞 → 脑水肿、惊厥、脑疝、脑桥髓鞘溶解。
对比维度急性高钠（<24–48 h）慢性高钠（>48–72 h）
脑细胞状态皱缩，尚未产生渗透分子已建立渗透分子适应
主要风险桥静脉撕裂、颅内出血快速纠正 → 脑水肿
降钠速度可稍快（≤1 mmol/(L·h)）必须慢 ≤0.5 mmol/(L·h)
典型场景ELBW 经皮失水快速进展母乳喂养失败数日、喂养不当
🔑 推论
ELBW 高钠常在生后 24–48 h 内经皮失水飙升，脑细胞来不及造渗透分子——此时纠正反而可以稍快、不易脑水肿；而几天喂养不足攒出来的慢性高钠，必须死守 48–72 h。判断急慢性看三样：起病时间、体重下降曲线、临床稳定度。

配液前先把账算清：维持 + 既往丢失直接算总量；自由水缺口不单独配——它"藏"在两路泵的张力比例里，这是整套配液的核心思想。

① 维持量
不显性失水：足月儿约 40 mL/(kg·d)（辐射暖箱再 +20）＋ 尿量 50–60 ＋ 大便 0–10 → 合计约 100 mL/(kg·d)。光疗、早产按不显性失水上调。
② 既往丢失
出生体重 − 当前体重（1 g ≈ 1 mL），减去已经扩容给过的量——体重掉的那部分就是要补回的水。

配液

两路泵：越重越偏等张

不配一瓶"中间张力"的液——泵 A（D5·0.45%NS）与泵 B（D5·0.9%NS）两路同时走，床旁只调泵速比例：降快了关小 A 开大 B，不用换瓶。两路合并钠浓度介于半张与等张之间、随比例滑动（75/25 ≈ 96，25/75 ≈ 135 mEq/L）。

治疗三步走：顺序不能乱

1
循环不稳先等渗扩容（不要管血钠）
0.9% NS 10–20 mL/kg 静推；血压、灌注、尿量恢复后才进入降钠阶段。第 1 步直接上低张液是最常见的错误。
2
按血钠水平选两路液体的张力比例
越重越偏等张：中度 75% 0.45% + 25% 0.9%；重度 25% 0.45% + 75% 0.9%。
3
每 4 h 复查血钠，按实测速度回调两路泵速
降太快 → B 加 A 减；降太慢 → 反之；有尿后补 K⁺（口诀见上）。
关键顺序：等渗扩容 → 慢补自由水 → 床旁微调。任何一步反过来，都可能把孩子从高钠直接送进脑水肿。
🚫 三个「不要」：会"瞬间改张力"的操作都要克制
  • 高血糖不要急着打胰岛素——胰岛素把葡萄糖快速拉进细胞，瞬间改变 ECF 张力 → 脑水肿；除非渗透性利尿持续，先观察。
  • 代酸不要补 NaHCO₃——补碱本身就是加钠；靠改善灌注、PN 中用 acetate 慢慢纠正，不反复推。
  • 惊厥不是要降钠——用 3% NaCl 4–6 mL/kg：快速提高细胞外张力，把脑细胞里的水拉回血管。这是救命，不是为了升钠。

配液实例：从入院到两个泵速

Case 1 · 足月，出生 3000 g → 现 2400 g，Na 165，暂无尿，循环不稳
  1. 先扩容：0.9% NS 10 mL/kg ≈ 30 mL 静推——循环稳了再谈降钠。
  2. 定时间：165 → 145 需降 20，按 ≤0.5 mmol/(L·h) → 约 36 h。
  3. 算总液量（按 ~3 kg 估）：维持 40×3×1.5 ≈ 180 mL ＋ 既往丢失（3000−2400−已扩容 30）= 570 mL → 750 mL。
  4. 定泵速：750 ÷ 36 ≈ 20.8 mL/h；中度按 75/25 分两路：泵 A（D5·0.45%NS）15.6 mL/h ＋ 泵 B（D5·0.9%NS）5.2 mL/h。
  5. q4h 测 Na 调泵：降太快 → 泵 B 加、泵 A 减；有尿后加 K⁺ 1–2 mEq/(kg·d)。

场景

脑损伤后的水钠紊乱：三相病程

适用对象：重度 HIE、Ⅳ度 IVH/脑室内出血扩展、化脑、颅脑外伤、新生儿中风后的患儿。这类孩子下丘脑-神经垂体受损，水钠状态会在几天内自己反转——值班最需要的是"预告"和"认出反转"。

DI 相
伤后 1–6 天
DI 相受损神经元不能释放 AVP → 多尿 + 高钠（常于伤后 2–7 天显现）。
处理：算游离水缺失＋小剂量 DDAVP 滴定（第⑩页）；q4h 血钠；把"可能反转"预告给团队。
SIADH 相
约第 5–10 天
SIADH 相受损神经元膜不稳定，AVP 失控漏出 → 少尿 + 低钠。
处理：立即停 DDAVP＋限水（如减至维持量 2/3，同步提高营养液浓度）；症状性低钠按上级意见用 3% NaCl。此相禁给 DDAVP。
第 2–4 周
重新评估
永久 DI 约 2/3 围产期 CDI 迁延不恢复——自发多尿高钠复发 → 重启 DDAVP、垂体 MRI、垂体前叶激素轴评估；恢复 其余部分可逆，随访确认。

AVP 已经"漏"得够多了，再给抗利尿 = 放大自由水潴留 → 水中毒、低钠惊厥。DDAVP 治疗期间任何尿量骤减，第一反应都是停药，再找原因。

三相病程管理动作清单

  • 伤后第 2 天起：每日固定时间称体重 + 记每小时尿量 + 尿比重——反转的信号永远先出现在体重和尿量上。
  • 尿量突增：立即查血钠 + 尿比重 + 尿渗 → 低渗尿 + 高钠 = DI 相开始（降钠节奏见第④页）。
  • 确立 DI 相：算游离水缺失；DDAVP 0.05 μg 静注起滴定；交班口头预告"5–10 天可能转 SIADH 相"。
  • 尿量骤减 + 血钠下滑：先停 DDAVP，再查因——不要先"找原因"而让药继续输。
  • SIADH 相：限水（减至维持量 1/2–2/3，同步提高营养液浓度保证热卡）；顽固性低钠联合呋塞米＋补钠方案由上级定。
  • 2–4 周后复评：自发多尿复发 = 永久 DI → 垂体增强 MRI + GH/ACTH/TSH/LH/FSH 全轴评估（CDI 分论见第⑥页）。

A类

② 中枢性尿崩症（CDI）五个亚型

CDI = AVP 分泌不足，阀门上游断了。新生儿期先记两个最常见：围产期获得性（有脑损伤史）与 PSIS（围产期垂体柄损伤）。

① PSIS 垂体柄中断综合征
机制：围产期垂体柄被牵拉/断裂（臀位产、第二产程延长、剖宫产、枕后位）→ 下丘脑 AVP 运输中断。
MRI 三联征：垂体柄中断 + 垂体后叶异位/缺如（正常 T1 高信号不见于蝶鞍后部）+ 垂体前叶发育不良。
表现：生后数天–数周多尿高钠、脱水；常合并多种垂体前叶激素缺乏（GH 最常见 ~70%，其次 TSH / ACTH）。
治疗红线：先补皮质醇，再补 DDAVP——糖皮质激素有轻度水利尿作用，未补皮质醇时 DDAVP 效果不稳定。按需补充 GH、LT4。
预后：规范替代下生长发育可正常；终身随访垂体功能。
④ 围产期获得性 CDI（NICU 最常见）
病因：重度 HIE、Ⅳ度 IVH / 脑室内出血扩展、化脑、颅脑外伤、新生儿中风。
典型时间窗：伤后 2–7 天出现多尿高钠。
三相病程：DI 相 → SIADH 相（禁 DDAVP）→ 永久 DI 或恢复 → 第⑤页
处理：DDAVP 滴定（第⑩页）+ 同步防治脑水肿、出血本身。
预后：取决于原发病；部分可逆，2–4 周后重新评估，别急着下"永久"结论。
② 家族性 CDI（AVP–NPⅡ 突变）
遗传：常染色体显性。
机制：突变 AVP–NPⅡ 前体错误折叠 → 内质网蓄积毒性 → 视上核神经元变性死亡。
起病特点：不是生后即病，而是生后数月到数年渐进性加重——早期多饮多尿被家长忽略，3–6 岁才确诊。
治疗：DDAVP 替代，终身。
③ Wolfram 综合征（DIDMOAD）
四联征（DIDMOAD）：DI 尿崩 + Diabetes Mellitus 糖尿病 + Optic Atrophy 视神经萎缩 + Deafness 感音神经性耳聋。
机制：WFS1 基因（常隐），内质网应激。
新生儿期：DI 可先于糖尿病出现；糖尿病通常 6 岁前发病——多尿患儿血糖必查。
随访：视神经、听力、膀胱/自主神经、精神心理。
⑤ 肿瘤 / 浸润性疾病（晚发，新生儿期罕见但必须随访）
病因：生殖细胞瘤、颅咽管瘤、朗格汉斯细胞组织细胞增生症（LCH）、白血病浸润。
临床提示：原因不明的 CDI、尿崩持续不恢复、垂体后叶 T1 高信号消失后 6 个月–2 年内垂体柄增粗。
随访：每 6–12 个月复查垂体 MRI，持续 2–3 年。

A类

③ 肾性尿崩症（NDI）：阀门本身坏

NDI = 集合管对 AVP 无反应——V2 受体或 AQP2 水通道的问题。DDAVP 无效（除非部分反应的特殊突变）。遇到"高钠 + 低渗尿 + DDAVP 试验不升"就是它。

① X 连锁 NDI（AVPR2 突变，~90%）
遗传：X 连锁隐性，男婴发病；女性携带者可因 X 失活偏移有不同程度症状。
起病：生后 1 周–3 月——新生儿期最常被误诊为"喂养不耐受"、感染性发热（→ 第⑨页陷阱 1）。
典型表现：高钠脱水、发热（脱水热）、易激惹、哭闹喂奶后缓解、便秘、体重不增；未治可惊厥、昏迷。
治疗：DDAVP 无效；低溶质饮食 + 噻嗪 + 阿米洛利 ± NSAID → 第⑩页方案
预后红线：早期诊断规范治疗者神经发育可正常；反复高钠 >150 是智力低下/癫痫的首要可预防原因。
② AQP2 突变 NDI（~10%）
遗传：常隐或常显，男女均可。
严重度：通常比 X 连锁 NDI 轻；部分患者对高剂量 DDAVP 有部分反应（水通道还在，只是运输/表达缺陷）——别因"用了 DDAVP 有点效"就排除 NDI。

A类

④ 肾小管病：七个病，一张速览表

这类病的多尿常是"梯度坏 + 溶质丢"双重机制，尿渗可低可不低——别用尿渗一刀卡死，靠"酸碱 + 血钾 + 尿钙"三件套定位。

多尿机制怎么定位
Bartter = 髓袢坏 → 梯度坏（水利尿成分）；Fanconi = 尿里糖/氨基酸/磷酸盐 → 溶质性成分；dRTA = 失钠失钾 + 梯度受损。尿渗落在灰区（200–300）先想到它们。

各病要点与处理

dRTA（Ⅰ型远端 RTA）
机制：α 闰细胞 H⁺-ATP 酶或 Cl⁻/HCO₃⁻ 交换体失败，尿 pH 降到 5.5 以下的能力丧失。
表现：生后即生长落后、呕吐、脱水；婴儿期"脱水热"。
化验：高氯代酸 + 尿 pH >6.0 + 低钾 + 高尿钙 + 肾钙化/肾结石。
治疗：碳酸氢钠 2–5 mmol/(kg·d) 或枸橼酸钠钾合剂；补钾；多饮水防结石。
预后：早期规范治疗生长可正常；未治 → 佝偻病、肾钙化、慢性肾衰。
Bartter 综合征
机制：髓袢升支粗段 NKCC2 或其通道突变（常隐），类似长期呋塞米。
亚型：Ⅰ/Ⅱ型 = 新生儿型（羊水过多、早产、生后多尿脱水）；Ⅲ型 = 经典型（年长儿）；Ⅳ型伴感音神经性耳聋。
化验：低钾、低氯、代谢性碱中毒、高肾素高醛固酮、血压正常、高尿钙。
治疗：大剂量补钾；吲哚美辛 1–3 mg/(kg·d)；螺内酯/阿米洛利；补水补钠。
Gitelman / Fanconi / Lowe / Dent
Gitelman：远曲小管 NCCT 突变（常隐），噻嗪样；年长儿起病，新生儿罕见；低镁 + 低尿钙；补钾补镁。
Fanconi：近端葡萄糖/氨基酸/磷酸盐/碳酸氢盐/尿酸重吸收全部失败；婴儿型病因 = 胱氨酸病（CTNS）、Lowe、Dent、遗传性果糖不耐受；治疗补碱补磷、活性 Vit D、补钾；胱氨酸病用半胱胺。
Lowe：X 连锁 OCRL，男婴；三联 = 先天性白内障 + 肌张力低下/智力障碍 + Fanconi 样小管病——红光反射筛查。
Dent：X 连锁 CLCN5/OCRL；低分子蛋白尿 + 高钙尿 + 肾钙化，最终慢性肾衰。
PHA-1（假性醛固酮减少症Ⅰ型）
新生儿表现：生后数天严重失盐——低钠高钾、脱水、酸中毒，酷似肾上腺危象（先天性肾上腺皮质增生）。
鉴别钥匙：17-OHP/皮质醇正常、醛固酮极高（受体坏了，身体拼命分泌）。
治疗：大量补钠 10–20 mmol/(kg·d)；氟氢可的松无效（受体抵抗——不是缺激素，是听不见）。多数随年龄好转。
B类

溶质性利尿（尿渗 >300）：尿里"带着货"

尿量 = 溶质排泄量 ÷ 尿浓度——货多就必须多排尿。治疗核心永远是去掉溶质来源，而不是单纯"多补水"。

B1

高血糖相关（先查它——一条指尖血糖 1 分钟）

应激性高血糖
早产儿、RDS、感染、窒息后，糖速 >6–8 mg/(kg·min) 即可出现。处理：降糖速、查感染。多尿随血糖回落。
新生儿糖尿病
生后 1–8 周起病，消瘦、脱水、糖尿；KCNJ11/ABCC9 突变——磺脲类口服有效（可免胰岛素）。
查血糖立刻和 DI 分开。→ 第⑨页陷阱 4
🧮 高血糖时血钠要校正
高血糖把细胞内水"拉"进血管稀释血钠：血糖每高于正常 5.6 mmol/L，实测血钠 +1.6。例：血糖 28 mmol/L、实测 Na 158 → 校正后 ≈ 165——真实的高钠比化验单更重。
B2

TPN / 溶质负荷（NICU 溶质性多尿最常见）

氨基酸、葡萄糖、电解质负荷高 → 尿素与电解质排泄增加，常伴 BUN 升高。识别：把医嘱当溶质来源算一遍——糖速多少、蛋白多少、钠氯总量多少；降负荷后好转即可证实。与"补液过多"（水利尿成分）常并存，看尿渗定主次。
B3

梗阻后利尿（男婴 PUV 术后）

后尿道瓣膜（男婴，产前膀胱扩张/羊水过少/双侧肾积水）解除梗阻（置管/手术）后 24–72 h 排出大量等渗尿——梗阻期蓄积的尿素与钠一起冲出来（尿渗 ~300、尿钠高）。
管理：按前一日尿量的 1/2–2/3 补等张液，数天自限；不要按"休克补液"猛灌——补过量就是水过荷（体重骤增、前囟饱满）。→ 第⑨页陷阱 2
B4

ATN 多尿期

围产期窒息、肾静脉血栓后，少尿期 → 多尿期：坏死的肾小管再生初期浓缩与重吸收功能未恢复。等容量补液（补出多少补多少），监测血钾——多尿期丢钾与排钾功能不全并存，血钾可高可低，都危险。
B5

高钙 / 低钾（两个"功能性 NDI"钥匙）

高钙抑制 AQP2 转位；低钾破坏髓质高渗梯度（第②页原理）。两者都让浓缩功能打折——原因不明的多尿/NDI 样表现，先查血钙血钾，纠正后常自愈。

误诊陷阱复盘：四个最贵的坑

四个陷阱有一个共同点：漏掉的都是 5 分钟内可得的床旁数据（尿比重、血糖尿糖、体重、尿渗）。看完这页，把"先做便宜检查"刻进肌肉记忆。

陷阱 1

NDI 被当成"喂养不耐受 / 感染"

病例
男婴 6 周，反复发热 38.5–39.5 °C，吃奶差、呕吐，在外院两次诊为"败血症 / 喂养不耐受"，用抗生素 + 换配方，体重仍不增。来诊时前囟凹陷、皮肤干，血钠 162，尿比重 1.003。
为什么会误诊
① NDI 婴儿不会说"口渴"，只表现为哭闹、喂奶后缓解——被当成"闹奶"；② 脱水热被当成感染热；③ 反复查尿都被当成"尿布多"而忽略比重。
✓
底线动作：任何不明原因反复发热的小婴儿，第一步查尿比重 + 血钠。比重 <1.005 + 高钠 = NDI，不要等血培养。→ 第⑦页 NDI
陷阱 2

PUV 梗阻后多尿被当成"败血症脱水"猛补

病例
男婴产前超声膀胱大、羊水少。生后置管引出大量尿，第 2 天尿量 8 mL/(kg·h)，血钠 132、BUN 升高、心率快。医生按"脱水 / 休克"加快补液，结果 24 h 后体重增 5%、前囟饱满。
问题在哪
PUV 解除后的多尿是等渗性利尿（尿渗 ~300、尿钠高——蓄积的尿素和钠冲出来），不是低渗性脱水。这种孩子本来就低容量，补等张液没错，但要按"前一日尿量的 1/2–2/3"补，不是按休克补。鉴别点：尿渗 >300（不是 <200），尿钠高。
✓
底线动作：男婴"产前泌尿系异常 + 术后多尿"，先看尿渗——等渗尿按梗阻后利尿管理，不要套用 DI 的低张液方案。→ 第⑧页 B3
陷阱 3

CSW 与 SIADH 混淆：限水限出休克

病例
化脑恢复期患儿，血钠 128、尿钠 70，体重较病初下降、心率偏快、四肢凉。值班见"低钠 + 高尿钠"，按 SIADH 限水到 60 mL/(kg·d)。次日血压下降、尿量骤减——患儿其实是脑性耗盐（CSW）：低容量失钠，限水方向完全反了。
问题在哪
SIADH = 等/高容性低钠，限水对；CSW = 低容量失钠，限水会血管塌陷。两者化验完全一样（低钠 + 尿钠 >40），唯一可靠鉴别是容量状态——这个患儿体重在掉、心率快、末梢凉，容量证据摆在面前却被跳过了。
✓
底线动作：每次低钠高尿钠，先回答一个问题——这个孩子是湿还是干？看血压、心率、体重变化、皮肤灌注。拿不准时不要先限水，先补等张液看反应：CSW 补钠好转；SIADH 补等张液只是临时扩容，不会加重低钠（低钠根因是自由水过多）。→ 第⑤页一表定乾坤
陷阱 4

新生儿糖尿病被当成"高钠脱水 / NDI"

病例
女婴 6 周，体重下降 15%，脱水貌，血钠 158，尿比重 1.012。按"高钠脱水"给 0.45% NaCl + 5% GS，结果血糖飙到 28 mmol/L，出现惊厥。
问题在哪
① 高血糖渗透性利尿的尿是等/高渗的（尿里有糖），不是低渗；② 尿比重 1.012 本来就不支持 NDI（NDI 应 1.001–1.005），这个信号被忽略了；③ 高血糖稀释血钠——血糖每高 5.6，实测 Na +1.6，这个孩子真实血钠可能是 165 而不是 158；④ 首选液里还有 5% GS，等于火上浇油。
✓
底线动作：任何多尿 / 脱水，先查血糖和尿糖，再看尿比重。高血糖 + 糖尿 + 消瘦 = 新生儿糖尿病，不要先补含糖液。→ 第⑧页 B1
🔑 四个陷阱共同点
床旁第一小时把便宜检查做齐：尿比重 + 血钠 + 血糖 + 尿糖 + 精确体重 + 医嘱单过一遍。这六样东西拦住了本页全部的坑。

NDI

NDI 治疗：DDAVP 无效，两条腿走路

营养（基石，先于药物）
低溶质饮食：钠约 1 mmol/(kg·d)，蛋白适量——低电解质配方，必要时胃管喂养。自由水随时可得：学会走路前由医护/家长按时喂水，不能靠"孩子会要水"。目标：让必须排出的溶质最少，尿量自然降。
联合用药逻辑
氢氯噻嗪制造轻度容量耗竭 → 近端水钠重吸收↑ → 到达集合管的原尿↓（"以毒攻毒"，第②页）；阿米洛利保钾抵消噻嗪低钾；NSAID 抑制 PGE2 → 撤掉 AQP2 的"刹车"。三条通路指向同一目标：让水回来。

随访

预后与随访：把"可预防的残疾"拦住

CDI
  • 规范替代下生长发育正常。
  • 原因不明者：每 6–12 个月复查垂体 MRI，持续 2–3 年（盯肿瘤/浸润）。
  • 合并多种垂体激素缺乏者长期随访；糖皮质激素替代后 DI 症状会"显现"。
  • 围产期获得性部分可恢复，数周后重新评估（~1/3）。
NDI
  • 预后取决于诊断时机：反复高钠脱水是智力残疾/癫痫/生长落后的首要可预防原因。
  • 生长双相：1.5 岁时矮身材 ~39%，儿童后期追赶。
  • 长期未控：肾盂积水、膀胱壁厚、反复尿感。
  • 遗传咨询：AVPR2 X 连锁——母亲携带者男胎 50% 发病，产前可评估。

随访清单

  • 生长：体重/身长/头围曲线，每 1–3 月。
  • 代谢：血钠（稳定后可拉长间隔）、血钾（用噻嗪者必查）、肾功能。
  • 泌尿：尿常规/尿感监测；肾超声（肾钙化、肾盂积水、膀胱壁）定期。
  • 发育：神经发育评估（NDI 患儿每 6–12 月）。
  • 基因与家系：基因确诊后家系遗传咨询；CDI 原因不明者垂体 MRI 随访计划（见上）。
  • 家长教育：发热/呕吐/腹泻 = 水与 DDAVP 的调整日；随身备水；识别脱水热的早期信号。

① 尿崩症与水钠核心

缩写全称与床旁一句话
DIDiabetes Insipidus 尿崩症——CDI 与 NDI 的总称：浓缩环节坏了，水留不住，尿多而稀。
CDICentral DI 中枢性尿崩症——AVP 分泌/释放不足（阀门上游断了）：DDAVP 试验有反应、替代有效。
NDINephrogenic DI 肾性尿崩症——肾脏对 AVP 无反应（阀门本身坏）：DDAVP 经典无效（AQP2 部分突变例外）。
SIADHSIADH 抗利尿激素分泌不当综合征——AVP 失控漏出 → 少尿＋低钠，治疗限水；脑损伤后三相病程的第二相。
CSWCerebral Salt Wasting 脑性耗盐——脑损伤后尿排钠丢水，低容量，治疗补钠补水；与 SIADH 化验相同、容量相反（第⑤页一表）。
AVPArginine Vasopressin 精氨酸加压素＝抗利尿激素 ADH——九肽，视上核/室旁核合成、神经垂体储存释放。
DDAVPDesmopressin 去氨加压素——AVP 类似物（1-脱氨-8-D-精氨酸加压素），抗利尿强、升压作用几乎无；CDI 的替代药与诊断试验用药。
copeptinCopeptin 和肽素——AVP 前体 C 端的稳定片段，血中不易降解，切点 2.6 / 4.9 / 21.4 pmol/L（见公式卡）。

2DDAVP 试验怎么判？0.05 μg 静注后 30/60/120 min：尿渗升 >50% 或绝对值 >600 = CDI；<9% = NDI；之间 = 部分性 CDI。
3男婴反复高钠脱水先查什么？床旁先查尿比重 + 血钠；家族史问母系男性；定向查 AVPR2（→AQP2）基因。
4高钠为什么不能快纠？>48 h 脑细胞已合成有机渗透物，快降钠 → 自由水入脑 → 脑水肿/惊厥/渗透性脱髓鞘；≤10–12 mmol/(L·24 h)。
5NDI 能用 DDAVP 吗？经典无效（受体/水通道坏）；AQP2 突变部分患者高剂量有部分反应；Ⅱ 型 AVPR2 突变的药物伴侣在临床试验中。
6脑损伤后今天多尿明天少尿？三相病程：DI 相（伤后 1–6 天）→ SIADH 相（5–10 天，禁 DDAVP）→ 永久或恢复（2–4 周复评，~1/3 恢复）。
7医源性多尿怎么识别？先看出入量与用药（呋塞米/茶碱/激素/甘露醇/两性霉素 B/光疗补液）；停药或减量后尿量回落即证实。
8血钠 166 怎么补？循环不稳先 0.9% NaCl 10–20 mL/kg 扩容；总液量 = 维持＋既往丢失，自由水缺口（≈4×kg×21）不单独配——按「中度 150–169」走两路泵 75% 0.45%＋25% 0.9%，≤0.5 mmol/(L·h)，q4h 查钠调泵速。
9CDI 为什么查 ACTH（全垂体轴）？PSIS 等常合并前叶多激素缺乏（GH 缺乏 ~70%）；且必须先补皮质醇再补 DDAVP，否则效果不稳定。
10copeptin 多少提示 NDI？≥21.4 pmol/L 提示 NDI；基线 <2.6 或高钠状态 ≤4.9 支持 CDI。
